# FillPro Privacy Notes

Last reviewed: 2026-06-13

FillPro does not run a cloud profile account for form values. Saved profiles, rules, custom fields, and upload matches stay inside the browser extension unless the user exports them, contacts support, or chooses Pro billing.

Billing for Pro is handled by ExtensionPay and Stripe. FillPro does not see card details.

Support emails are separate from saved extension profiles and should not include passwords, payment cards, one-time codes, IDs, customer records, or full profile values.
