Questions fréquentes

Quels formulaires FillAhead peut-il remplir ?

Candidatures, inscriptions, intégration, fournisseurs, support et autres formulaires web répétitifs dont les champs sont accessibles.

FillAhead fonctionne-t-il hors ligne ?

Oui. Le parcours normal avec les profils enregistrés fonctionne hors ligne. La licence Pro, le support et les téléchargements nécessitent une connexion.

FillAhead remplace-t-il un gestionnaire de mots de passe ?

Non. Les identifiants, cartes et codes à usage unique restent dans les outils conçus pour ces données.
