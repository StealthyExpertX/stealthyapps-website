What changed in FillPro.

Release notes for the public FillPro extension. The product page stays focused on buyers; this page keeps the shipping history easy to scan.

Current release: 1.0.0

Prepared for Chrome, Edge, and Firefox packaging, with the Chrome product page and support pages updated for the release.

June 12, 2026

Version 1.0.0

  • Improved handling for React, Vue, Angular, custom elements, Shadow DOM, and same-origin iframe forms.
  • Better support for comboboxes, searchable selects, segmented phone fields, split birthdays, country, state, and month aliases.
  • Added profile fields for middle name and pronouns.
  • Cleaner popup, side panel, profile picker, pricing, and upgrade screens.
  • Expanded local tests for component libraries, real-world form patterns, file uploads, and monetization flows.
Before launch

Core FillPro build

  • Local profile storage in the browser extension.
  • Free tier with 3 saved profiles.
  • Pro profiles, duplication, import, export, and advanced repeat-use workflows.
  • Intentional skip rules for passwords, payments, CVCs, IDs, tax IDs, and one-time codes.
  • Undo last fill, field learning, custom fields, and resume-style upload matching.
