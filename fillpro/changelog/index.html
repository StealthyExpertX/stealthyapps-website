Initial release

Version 1.0.0

The first public version of FillPro.

Saved profiles

Create reusable profiles for personal, work, applicant, vendor, and other repeated form details.

Form filling

Fill normal forms and modern controls from the popup, side panel, on-page button, right-click menu, or keyboard shortcut.

Uploads and custom fields

Match resumes, cover letters, documents, CSV files, and spreadsheets to reachable upload fields. Add custom fields and Smart Rules for unusual labels.

Review and undo

See what FillPro changed, review the page before submitting, and undo the most recent fill when the page still contains the same fields.

Privacy and access

Use the core workflow without a profile-storage account. FillPro keeps required browser permissions narrow and asks for optional site access only when you enable site features.

Free and Pro

Free includes three saved profiles. Pro adds up to 500 profiles, profile duplication, and import/export backups.
