Skip Retyping/Getting started

Setup guide

Fill your first form with Skip Retyping.

Create a profile, open a form, and choose Fill Page. Skip Retyping changes the fields it can match and leaves the final review and submit to you.

First profile

Save only the details you reuse.

  1. Pin Skip Retyping from the browser's Extensions menu so it stays easy to reach.
  2. Open Skip Retyping and choose Create profile.
  3. Give the profile a clear name such as Work, Personal, or Job applications.
  4. Add the details you type often. Leave anything you do not want Skip Retyping to use blank.
  5. Choose Save Profile.

Three profiles are included free. You can edit or remove them whenever you need to.

First fill

Open the form first.

  1. Open a regular website with the form visible.
  2. Open Skip Retyping from the toolbar.
  3. Choose the profile meant for this page.
  4. Select Fill Page.
  5. Review the changed fields before you submit.

Need to reverse the fill?

Open Skip Retyping again and choose Undo. It restores the values from the most recent Skip Retyping fill.

Shortcuts

Open Skip Retyping whichever way is quickest for you.

Toolbar

Pick any saved profile and choose Fill Page.

Keyboard

Press Ctrl+Shift+F to fill with the default profile. You can change the shortcut in Settings.

Side panel

Keep Skip Retyping beside a longer form while you work through it.

Right-click

Use Skip Retyping commands without leaving the page.

Optional

Show the Skip Retyping button only where you want it.

Right-click a regular webpage and choose Show Skip Retyping button on this page. Chrome asks for access to that site so the button can remain available there.

To remove it, right-click the page and choose Remove Skip Retyping button from this page. The toolbar action does not request access to every website during installation. Auto-fill uses your default profile only on sites you grant access to.

Save from a form

Keep one filled field without opening the profile editor.

  1. Enter the value on the page.
  2. Right-click that field and open Skip Retyping.
  3. Choose Save this field to a profile.
  4. Check the field name and value in the preview, then choose the profile that should remember it.

Skip Retyping does not offer this action for passwords, payment details, verification codes, searches, blank fields, or unsupported controls.

Uploads

Match a file to the wording on the form.

  1. Edit the profile and open File uploads.
  2. Add a resume, cover letter, CSV, spreadsheet, or other supported file.
  3. Enter a short target match such as resume, cover letter, or csv upload.
  4. Save the profile and run Fill Page with the upload control visible.
  5. Check the attached filename before submitting.

Custom fields

Save an answer that is not in the main profile.

Use a custom field for details you enter often but do not see in the standard profile, such as department, team size, CRM owner, or preferred contact method.

  1. Edit a profile and open More fields.
  2. Under Custom fields, choose Add field.
  3. Give it a clear name that resembles the wording used on forms.
  4. Enter the answer, save the profile, and review the next fill.

If one site uses unusual wording, keep the custom field and add a Smart Rule for that label.

Back up or recover your profiles.

Open More tools and choose Export. Skip Retyping checks every saved attachment before offering the download. Large collections have several parts; download and keep all of them. These files are not encrypted.

Choose Import, open a backup part and select the profiles you want. Existing profiles are kept unless you explicitly select a matching profile to replace. Free users can recover up to 3 selected profiles within the free limit; Pro supports up to 500. Import the other parts separately when recovering a multipart backup.

Keep backups somewhere private: they contain readable profile details and attached files. If an attachment is missing or storage is full, Skip Retyping stops backup preparation instead of offering an incomplete copy.

Pick up an unfinished profile.

The editor saves a local draft as you work. If you close it before saving a profile, choose Review saved drafts when you return. Incomplete fields, rule text and completed file reads are kept for review. A file that was still loading must be selected again.

If draft saving fails, keep the editor open and choose Retry draft save. A crash can lose edits that had not reached storage, so check the draft status before closing the browser.

Deleted profiles appear under More tools > Recovery. Restore a copy as a new profile, or discard it permanently. Erase profile data removes profiles, attachments, drafts and recovery copies together; it does not cancel a subscription or remove downloaded backups.

If a field misses

If a form loads late, run Skip Retyping again.

  • Open hidden tabs, accordions, or the next step before filling.
  • Open a searchable dropdown once, then run Skip Retyping again.
  • Use a Smart Rule when a site gives a familiar field an unusual label.
  • Use the support form for a repeatable miss. The page URL and field label are usually enough.
