## Privacy Practices

Single purpose:
FillPro stores local profiles and fills repeated web forms when the user chooses to fill them.

Data use:
- Profile data is stored in browser extension storage.
- Support messages are sent only when the user submits the contact form.
- Billing is handled by ExtensionPay and Stripe for Pro.
- The extension does not sell personal information.

Permissions explanation:
- `activeTab`: fill the current page after user action.
- `scripting`: run the fill engine on the active page.
- `contextMenus`: add right-click fill and capture actions.
- `storage`: save profiles, rules, settings, and license state.
- `alarms`: schedule local extension maintenance and delayed prompts.
- `sidePanel`: open FillPro as a side panel.
- Optional `<all_urls>`: only for optional floating-button and auto-fill behavior.
