## Long Description

FillPro is a private autofill extension for the forms that browser autofill usually leaves half-finished.

Save the details you type again and again, then fill job applications, signup pages, demo requests, onboarding forms, vendor intake, support forms, QA profiles, and everyday business forms from profiles stored in your browser.

What it fills:
- Names, contact details, addresses, company details, profile links, messages, dropdowns, radios, checkboxes, textareas, and custom fields
- Resume, CV, cover letter, portfolio, and document upload fields
- Repeated profile details across job applications, intake pages, registration pages, onboarding flows, support pages, and admin forms

Why people keep it:
- Fill forms from named local profiles
- Start free without creating an account
- Use the popup, side panel, on-page picker, right-click action, or keyboard shortcut
- Add smart rules when a site uses an unusual label
- Undo the last fill before you submit
- Keep sign-ins and payment details with the browser, password manager, payment wallet, or site controls built for those flows

Modern form support:
FillPro is built for normal HTML forms and modern frontend patterns used by React, Vue, Angular, Material UI, Carbon-style fields, custom selects, comboboxes, Shadow DOM components, same-origin iframes, dynamic fields, split birthday fields, segmented phone fields, country and state aliases, contenteditable fields, ARIA radio and checkbox groups, Google Forms-style controls, and file inputs.

Privacy and control:
- Profile data stays in extension-managed browser storage
- Free use does not require sign-in or cloud sync
- Optional Pro licensing uses ExtensionPay and Stripe when you choose to upgrade
- Optional feedback diagnostics are prepared only when you opt in
- The floating fill button and auto-fill setting are off by default and use optional site access

Free and Pro:
Free includes 3 private profiles and the core fill workflow. Pro adds more saved profiles, duplicate profiles, import/export, and advanced repeat-use workflows. Try Pro free for 3 days with no card required.

How to start:
1. Create a profile with details you reuse often.
2. Open a normal web form.
3. Click Fill Page, choose a profile from the on-page picker, use the side panel, or press the keyboard shortcut.
4. Review the filled form before submitting.
